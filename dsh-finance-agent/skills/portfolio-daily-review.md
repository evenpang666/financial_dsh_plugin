# 持仓研究与三组仓位总结

用户要求分析已保存持仓、比较某交易策略或综合配置建议时使用。只做研究与风险管理，不连接券商、不发送交易指令。定时双时点日报不读取持仓；持仓分析在用户明确请求或网页点击后独立生成，不写入日报和持仓文件。

## 持仓证据与工具

1. 调用 `get_portfolio_position_review(market="a" 或 "hk", strategy=用户指定策略)`。未指定策略时省略参数，沿用控制面板选择；不要自行改为默认的另一策略。所选策略仅作用于本次请求，不写回设置。
2. 持仓为空时说明尚未保存该市场清单；可用 `set_portfolio` 保存代码、可选成本和数量。不要把无持仓当成分析失败，也不要索要券商密码或账户权限。
3. 核对每只股票的 `analysis.as_of`、最新财报期、技术/基本面证据、市场覆盖与缺失项。需要公告或同行核验时，再调用 `analyze_stock` 和 `get_related_large_enterprises`。日线 MA/RSI 与五分钟策略信号属于不同周期，不可把两者说成独立、同频的证据。
4. 人气榜只是关注度。它不可用时，仍可保留有效的价格情绪代理、MA/RSI 与财务分析；明确相关覆盖缺失，不把网络失败解释成公司风险或技术信号失效。用户输出只列来源和简洁原因，不复制 HTTP 查询串、主机、代理堆栈。

## 三组结果的计算与 AI 复核

工具返回 `position_summary`、`strategy_review` 和个股分析。数字由程序计算，智能体负责逐项审查证据、比较分歧并解释条件，不心算生成未经校验的权重。

- **建议1：个股研究配置。** 沿用当前工具的技术/基本面规则分析，展示明确结论、证据与配置权重。工具本身没有另行调用大语言模型，不得声称它已经完成一次独立 LLM 分析。AI 解释必须忠实于返回证据；买卖倾向不是仓位，不能直接抄作配置百分比。
- **建议2：所选策略配置。** 显示策略名称、描述、信号时点、持仓池范围、入场排名/评分与配置。该排序仅覆盖已保存持仓，不是全市场排行榜。经典策略调用与现有策略系统相同的入场规则；多因子模型策略必须已有有效训练产物。未触发入场表示不分配新增预算，不代表必须卖出现有持仓。
- **结果3：综合复核。** 同时审查1和2。双方支持时解释共同证据及相关性；1支持但2未触发时降低新增配置并等待确认；1反向、2触发时暂停新增并复核基本面。指出策略周期、数据日期、缺失来源和可能的反转/失效条件。程序基线为 `min(建议1, (建议1+建议2)/2)`，不重新归一化放大；有一组缺少完整输入或日期不一致时留空。若 AI 发现基线不适合，应明确“基线待复核”及原因，不能覆盖数字后伪称工具已验算。

## 仓位总结表

按股票输出：代码/名称、研究数据日与策略信号日、当前登记股票市值占比（不含现金）、建议1及依据、所选策略建议2（排名、评分、是否触发）、综合结果3及分歧解释。末尾列三组股票配置合计与预留现金，再列适用范围与计算方法。

三组百分比使用同一**假设研究预算=100%（股票配置+预留现金）**，用于比较新增资金的研究配置，不是用户个人总资产仓位或交易数量。市场风险预算按工具给出的上限使用，单股最多25%；超出上限的余量保留现金。数量或价格缺失时，当前股票市值占比留空；不能假设现金、成本、总资产，也不能将其与研究预算权重相减后生成调仓数量。

任一持仓缺关键输入时，对应整组数值配置及现金合计留空，保留能核验的个股结论；港股策略尚未接入时，明确2/3不可用，不套用 A 股信号。模型未训练、过期、分钟线不完整、日期不匹配、休市或盘前没有当日已完成线时，都不能补造策略权重。

## 双时点日报与反馈

用户要求日报时，先用 `get_trading_day` 核验交易日，再调用 `get_daily_research_report(session="morning" 或 "afternoon")`。日报2只用两次快照价格、当日涨跌、市场风险分变化和可核验披露判断一致性，不凭叙事补写原因。复盘反馈需保留样本量和有限校准，不把一次相符当作收益或因果证明；它不自动调整真实持仓。

最终说明：买卖倾向是证据方向分；配置权重是带现金与上限的研究预算方案。两者都可能随新数据变化，不保证收益，也不执行交易。
