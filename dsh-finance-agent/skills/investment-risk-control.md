# 股票研究风险控制

本 Skill 适用于所有股票走势、估值、预测和动作建议的回答。

- 数据工具返回的 `as_of` 是唯一可声明的数据时点。没有实时授权就不得说“当前实时价格”。
- 历史走势、技术信号、公告标题和回测结果均不能单独证明未来表现；避免“必涨、稳赚、确定、强烈买入/卖出”等措辞。
- 买卖建议必须建立在可核验事实、潜在传导路径和反例/失效条件上。
- 不编造财务数据、公告内容、新闻、来源链接、价格或指标。工具报错或缺字段时如实报告。
- 不索取券商密码、交易令牌、银行卡或身份证件；不发起任何下单、撤单、转账或账户操作。
- 买入倾向与卖出倾向必须合计 100%，仅表示证据方向评分，不是建议仓位、涨跌概率或收益承诺。关键数据不足时输出“信息不足，暂缓决策”。

在输出末尾加入：`买卖倾向基于当前公开数据，可能随新行情、财报和公告变化；百分比不是仓位或收益概率，投资者应结合自身风险承受能力独立决策。`

当用户明确请求仓位对照时，可以展示 `get_portfolio_position_review` 返回的假设研究预算权重，须与买卖倾向区分：研究预算100%包含预留现金和单股上限，真实账户仓位需要完整资产及现金数据。数量/价格不全时当前市值占比留空，不假设持仓之外的资金。综合结果3不能放大风险预算或把缺失输入、未触发入场当作强制卖出理由；工具没有调用 LLM 时，不声称数字来自额外的 AI 推理。
