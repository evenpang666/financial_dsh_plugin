# 已核验的历史分钟线修正

此目录随项目代码分发，供没有任何本地缓存的新用户处理已确认的供应商历史错误。它不在被 Git 忽略的 `data/factor-lab/` 运行目录内。仅当原始分钟线未通过验收时，准备脚本才按股票与交易日查找修正记录；正常数据不会被覆盖。

## 601091，2026-09-21

2026-10-12 重新请求 BaoStock 后，该日 09:45 行仍存在成交均价低于最低价的问题，且整日分钟成交额合计为 7,408,662,163 元，高于日线的 6,770,866,376.39 元。

同期新浪未复权 5 分钟数据的成交额合计为 6,767,849,692.8555 元，接近日线总额，并通过价格、成交量、成交均价及时间戳校验。新浪不返回 09:40、09:50 两个窗口，BaoStock 在这两个窗口明确记录零成交；修正数据使用新浪此前已发生交易的收盘价，成交量和成交额均为零。没有为缺少的有成交 K 线插值。

文件包括：

- `601091_2026-09-21.baostock.csv`：最初保留的异常交易日。
- `601091_2026-09-21.sina.csv`：备用源原始交易日回复，含 46 根 K 线。
- `601091_2026-09-21.csv`：经过上述零成交窗口处理的 48 根未复权 K 线。
- `601091_2026-09-21.json`：来源 URL、核验时间、异常样例、日线参考金额及三个文件的 SHA-256。

加载时重新检查文件哈希、完整时间集合、价量关系，以及当前日线总额是否与核验记录一致。应用后另在用户运行目录保存原始输入、采用的修正数据及带哈希的修复记录。这样即使新浪近期接口不再覆盖该日，也能修复此次已确认的错误。

未登记的新异常仍尝试在线备用源；若所有可用来源都缺失或无法通过校验，则保留诊断并停止准备，不能删除异常股票或放宽校验生成回测收益。
