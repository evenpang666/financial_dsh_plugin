## 六类风险

| 风险 | 审核与处理 | 剩余限制 |
| --- | --- | --- |
| 未来函数 | 信号特征仅使用信号时点及以前的 K 线；执行延后一个完整 K 线。红股在实际上市交易日前仅计入资产、不计入可卖出数量。拟合只使用退出日在测试窗口前的成熟标签，训练/验证边界也清除跨边界标签。修复了卖出后的持仓变化影响买入预算，以及先前买单部分成交/失败影响后续订单的问题：全部买单数量与完整现金预留在任何成交前冻结。`known_at` 按上海时区比较绝对时间，不能用时区偏移伪装前日。 | 五分钟 VWAP 是执行模拟量，不是下单时已知价格；不能恢复窗口内路径、撮合顺序和到达延迟。公司行为的供应商历史记录也不是公告原始快照。 |
| 幸存者偏差 | 股票池逐日从前一交易日全市场成交额构建，并非今天的 40 只股票倒推。BaoStock 基础资料含历史退市记录，本地缓存有 337 条退市日期。历史名单中缺少基础资料时不再静默排除该股票；缺状态不再伪装为停牌；非停牌候选缺特征时拒绝生成绩效。深市 `399` 指数也明确排除。 | 供应商回填名单不能证明覆盖全部历史证券；缺少退市后的清算或转板数据时拒绝通过完整性验收，不能将这类股票删除或按原价永久估值。 |
| 过拟合 | 用户预先指定唯一模型，不在每个窗口追逐最优算法。标准化器仅在对应训练集拟合；XGBoost 深度与正则参数、Elastic Net 正则规则固定。按交易日拆分并滚动评估；测试窗口不参与当期拟合。规则策略阈值固定，未按本次评估结果调优。 | 默认历史窗口约 120 日，股票及盘中样本存在相关性；年度化 Sharpe 未做自相关调整，样本少时年化指标不稳定。代码没有给出独立最终留出集上的显著性结论。 |
| 滑点与交易成本 | 保留每边滑点、最低佣金与卖出印花税；补上双向过户费，并按日期使用历史印花税/过户费率。佣金假定含交易规费，避免重复计费。现金分红预留 20% 税款，按实际到账日后释放净额，不能提前买股。输出费用、滑点及分红税预留。 | 分红税为保守预留，不是精确逐批税务账；长期持有可能多预留。送股税、补扣时点、具体券商费率仍未精确建模。固定滑点不等于真实价差和市场冲击。2015-08-01 前费率未建模，拒绝套用现行费率。 |
| 数据窥探 | 回测前写入 `backtests/plans/`，冻结策略清单、时点、输入文件哈希与代码哈希，并记录相同数据上已有的批次数；“回测全部”保留成功与失败记录，不自动选择赢家。日报明确标为探索性比较。 | 登记只能追踪本项目保存的试验，不知道外部或人工的全部搜索次数。未计算 PBO、DSR 或多重检验校正；看过比较结果再选赢家后，仍须使用未参与选择的新数据验证。 |

## 持有期口径

模型标签是一交易日的毛价格收益预测目标。组合每个交易日按配置的候选上限重审（默认五只）：仍被选中则继续持有，离开候选范围或没有入场信号才提交卖单；卖不出则保留持仓。因此实际持有期可能超过一天，并不承诺每天强制卖出。此前 README 的“下一交易日退出”表述过强，已经改正；新结果包含 `holding_policy`。

## 新增的验证

- 修改执行窗口卖出成交量与先前买单成交量，后续买单的预设数量保持相同。
- 时区偏移导致实际可知时间落在信号日的股票池被拒绝。
- 历史基础资料缺失、历史状态缺行、非停牌候选信号特征缺行不能被悄悄过滤。
- 交易费率在生效日切换；除息损失与净分红应收及税款预留相匹配。
- 卖出零股、科创板小余额、执行成交股数参与率限制分别验证；送转股上市前不得卖出，缺少上市日期时拒绝验收。
- 两种因子模型及八种经典策略使用同一评估区间；拟合仅含成熟标签；规则信号不读取未来收益标签。
- “费用/滑点加倍”和“成交参与率 2%”使用同一组已经生成的信号，不重新训练或据此挑选参数。

## 使用建议

重新运行所选策略或“回测全部策略”，比较基础与压力情景，而不是继续使用修复前结果。先经典策略、时点、费用假设与研究结束日；将后来新产生的数据用于独立验证。若缺少退市、停牌或公司行为数据，应补齐来源，不能缩减为只剩可回测的股票。不要把某次最高收益、最高 Sharpe 或正 Rank IC 当作消除了六类偏差的证明。

- [华泰期货 2022-04-29 官方研究材料](https://htfc.com/wz_upload/png_upload/20220429/1651191971569c77380.pdf)：2022-04-29 过户费下调前后的费率。
- [国家税务总局财税〔2015〕101号](https://www.chinatax.gov.cn/n810341/n810755/c1797427/content.html)：股息红利差别化税负。当前统一 20% 是代码中的保守预留假设，不代表所有持有期税率相同。
- [上交所交易规则（2026 年修订）](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)、[科创板投资者问答](https://edu.sse.com.cn/tib/qa/)：零股卖出和科创板最低申报数量。
- [BaoStock 维护者 API 文档](https://github.com/zxygithub/baostock/blob/master/docs/pythonAPI.md)：`dividStockMarketDate` 为红股上市交易日，与除权除息日分别记录。
- [Bailey 等：The probability of backtest overfitting](https://escholarship.org/uc/item/4w1110bb)：反复比较策略会形成选择偏差，仅有时间划分不能消除所有研究过拟合。

当前策略配置支持用户自选超参数与日期，并在运行前记录参数。经典策略不再扣除 120 日模型预备期；模型权重冻结，所选回测起始日须晚于 checkpoint 的训练集及标签结束日。旧回测结果仍保留其原始参数和日期，不与新结果混用。
