# 常见问题

[← 项目首页](../README.md) · [文档导航](README.md)

先查看控制面板的运行状态与日志；安装环境缺失时可使用“安装 / 修复”。

**Windows 控制面板一直显示“后台启动中”**：关闭旧面板后，使用最新代码重新运行 `control_panel.cmd`。启动日志会依次显示计划任务注册、数据服务和日报页面启动；服务退出或超时后会报告错误并恢复按钮。后台 Python 服务的详细错误保存在 `data/stock_data_server.stderr.log` 和 `data/report_web_server.stderr.log`，DSH Web 的错误保存在 `data/dsh-web.stderr.log`。若提示依赖缺失，使用“安装 / 修复”。

**服务正常，但按钮反复变灰**：旧版面板每 6 秒检查一次状态，检查期间会禁用按钮。最新版的后台检查和手动刷新均不再禁用操作按钮；检查期间也可打开网页或生成日报，较早的检查结果不会覆盖新操作的进度。关闭旧面板后重新启动即可加载修复。

**`dsh` 不是内部或外部命令**：关闭并重开 PowerShell；确认 Node.js 已加入 PATH，然后重新双击 `control_panel.cmd` 或运行“方式二”的备选命令。启动引导会自动安装缺失的 dsh。

**工具提示无法连接数据服务**：点击控制面板“刷新”检查服务状态；若数据服务未运行，关闭并重新打开控制面板。也可运行 `Invoke-RestMethod http://127.0.0.1:8765/health` 排查端口占用。

**AKShare 查询失败或字段变化**：升级依赖 `pip install --upgrade akshare`。若仍不稳定，应在 `scripts/stock_data_server.py` 的 Provider 层替换为 Tushare 或企业数据源；不要让模型以旧缓存补写数据。

**回测停在“检查 5 分钟线”**：此时正在下载、验收历史数据，尚未进入模型拟合和成交模拟，CUDA 不会加速网络取数。最新版会显示每只股票的代码、下载阶段与耗时；BaoStock 单次响应最多等待 60 秒，无数据传输最多等待 30 秒，网络失败后重连一次，仍失败就停止本次采集并保留缓存。重新启动控制面板后再次回测，会复用完整且通过验收的缓存。XGBoost 拟合会自动检测并使用可用的 CUDA；经典策略及 Elastic Net 使用 CPU。

**需要美股**：须新增经授权的对应市场数据适配器；不要将 A 股或港股代码规则用于其他市场。
