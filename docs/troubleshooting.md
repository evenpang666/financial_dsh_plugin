# 常见问题

[← 项目首页](../README.md) · [文档导航](README.md)

先查看网页的任务日志和启动终端；环境缺失时重新运行 `npm start` 检查依赖。

**DSH 无法启动**：确认 Node.js 已加入 PATH，重新运行 `npm start`。启动器会查找兼容 DSH 和 pnpm；也可用 `npm run dsh:register` 检查插件注册。

**工具提示无法连接数据服务**：运行 `npm stop` 后重新运行 `npm start`；取数服务由插件自动管理，内部端口由系统分配。

**AKShare 查询失败或字段变化**：升级依赖 `pip install --upgrade akshare`。若仍不稳定，应在 `scripts/stock_data_server.py` 的 Provider 层替换为 Tushare 或企业数据源；不要让模型以旧缓存补写数据。

**回测停在“检查 5 分钟线”**：此时正在下载、验收历史数据，尚未进入模型拟合和成交模拟，CUDA 不会加速网络取数。最新版会显示每只股票的代码、下载阶段与耗时；BaoStock 单次响应最多等待 60 秒，无数据传输最多等待 30 秒，网络失败后重连一次，仍失败就停止本次采集并保留缓存。重新启动工作台后再次回测，会复用完整且通过验收的缓存。XGBoost 拟合会自动检测并使用可用的 CUDA；经典策略及 Elastic Net 使用 CPU。

**BaoStock 提示 `timed out`，随后出现 UTF-8 解码错误**：超时可能发生在历史证券名单、日线、公司行为或分钟线采集阶段，端口连通并不代表这些查询都能及时返回。超时后继续使用同一连接可能读到上一条响应的残余字节，导致解码错误。数据准备流程会立即关闭异常连接，并重新登录后完整重试一次（包括分页），失败信息会标明接口用途及对应日期或股票；只有完整结果才写入缓存。不要同时启动多个 BaoStock 采集任务。

**需要美股**：须新增经授权的对应市场数据适配器；不要将 A 股或港股代码规则用于其他市场。
