## 复查

```sh

git ls-files -ci --exclude-standard

# 检查暂存区；不会创建提交。
git hook run pre-commit

# 覆盖忽略规则、强制添加、内嵌密钥、历史泄露及模板放行。

```

新克隆的仓库需运行 `git config core.hooksPath .githooks` 启用钩子。本地启发式检查不是完整的凭据检测服务；若以后确认真实密钥曾提交，应先撤销或轮换，再处理敏感历史。
