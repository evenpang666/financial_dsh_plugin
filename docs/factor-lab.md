# 因子研究与回测

[← 项目首页](../README.md) · [文档导航](README.md)

A 股研究支持 XGBoost、Elastic Net 和八种固定策略。数据准备、训练与回测各有独立验收条件。

## 研究流程

控制面板提供训练、回测、排序与批量回测入口，Windows 和 Linux 操作相同。

推荐用法：先在控制面板的“策略 / 模型”中选择 XGBoost、Elastic Net 或固定规则策略。训练、回测和排序都读取此选择，默认 XGBoost。因子模型每次只训练所选的一种；切换模型后分别读取各自保存的模型，所选模型尚未训练时会提示先训练。启用智能体后，每个工作日 12:00 检查所选因子模型的每周训练；本周成功一次便跳过，失败在下个工作日重试。固定规则策略无需训练，也不执行每周训练。回测信号时点默认 14:00，可选 09:35、10:30、11:30、13:30、14:30、14:50。点击“一键回测”时，如缺少逐日历史数据，控制面板会提示并自动下载、验收，成功后继续回测；下载或验收失败时不会生成收益。关闭控制面板后每周训练继续运行；安装或更新项目时会暂停，重新启用智能体后恢复。

## 历史数据准备与验收

历史数据准备：若本机 `config/tushare.token` 存在且能读取全市场日线，优先使用 Tushare；文件缺失、Token 无效或接口不可用时，自动改用 BaoStock 的逐日历史证券名单及未复权全市场日线，并尽可能用 AKShare 交易日历交叉核对。BaoStock 仍提供上市资料、逐日 ST/停牌状态、公司行为与未复权 5 分钟线；无需 Tushare 分钟线权限。Token 文件仅一行，已由 Git 忽略；自动选择数据源不读取 `TUSHARE_TOKEN` 环境变量。执行：

本仓库的 `.gitignore` 忽略所有 `*.token` 文件；本机已启用 `.githooks` 拦截误提交和误推送。新克隆仓库可运行 `git config --local core.hooksPath .githooks` 启用相同保护。不要用 `git add -f` 或 `--no-verify` 绕过这些保护。

```powershell
.venv\Scripts\python.exe scripts\factor_data_prep.py --start 2025-09-08 --end 2026-10-09
```

Linux 在项目目录运行：

```bash
./.venv/bin/python scripts/factor_data_prep.py --start 2025-09-08 --end 2026-10-09
./.venv/bin/python scripts/factor_lab.py backtest
```

首条命令需要联网获取历史数据；`--end` 应设为已收盘的交易日。只有数据验收通过并生成 `data/factor-lab/source-manifest.json` 后，第二条命令和控制面板的“一键回测”才可运行。已有的“一键训练”分钟线缓存不会自动生成这两个逐日文件。每只股票首次进入历史股票池前，还需下载前一交易日的完整分钟线，用于昨收价和跳空特征；验收会独立检查这一天。旧清单未记录 `feature_warmup_validated` 时，控制面板自动补齐并重新验收。

分钟线缓存即使已有 48 根，也需通过时间戳、数值、OHLC 与成交均价检查；分钟成交额合计不得超出对应日线总额的 1% 容差。BaoStock 返回异常交易日时，自动尝试新浪未复权 5 分钟线替换整日，完整校验后才写入缓存。备用源缺少有成交的 K 线时停止修复；只有原始源明确记录零成交的窗口，才可沿用该日备用源此前的收盘价。原始异常数据、备用回复和修复记录保存在 `data/factor-lab/source-cache/minute-repairs/`；验收报告会列出股票、日期、具体原因及异常样例。“已检查…失败 0”是取数步骤的进度，最终是否可回测以验收结果为准。

脚本按数据源分别缓存日线，按前一交易日成交额重建每日前 40 只股票池，检查历史名单、股票池、公司行为和完整 5 分钟线，通过验收后才发布 `universe-history.csv`、`market-state.csv` 和带 SHA-256 校验值的 `source-manifest.json`。首次使用公共数据需逐日下载证券名单、逐股下载全市场日线，可能耗时较久；中断后可重复执行。`--skip-minutes` 只验收已有分钟线，`--offline` 使用上次采集的日线来源缓存。涨跌停价依交易规则、未复权前收盘价及公司行为重建，并非交易所原始限价；若行情超出重建价格，脚本停止并要求补充核实。数据源历史回填不能证明供应商在过去交易时点实际已经交付全部数据，因此结果应标为“历史供应商数据重建”，不能当作当时真实留档的可交易信号。

已确认的 `601091 / 2026-09-21` 历史异常有随代码分发的[核验数据与来源记录](../data-corrections/minute/README.md)，新用户无需复制他人的运行缓存，且不依赖新浪近期接口继续覆盖该日。控制面板会比较输入文件与来源清单中的哈希，缓存变动后自动重新准备。回归测试使用独立临时目录和受控供应商回复，覆盖空缓存首次准备、部分下载后续传、首次入池预热、备用源不可用、修正文件损坏、准备失败不发布数据及不启动回测；这些测试不意味着外部数据服务永远正常。

## 训练、回测与排序

1. **一键训练**：验收通过后从逐日历史股票池训练；未准备历史数据时从当前成交额前 40 只 A 股建立探索性候选池（盘前成交额不可用时改用总市值），通过 BaoStock 回填近 400 自然日的 5 分钟行情，并用东方财富或新浪补齐近期行情，增量保存在 `data/factor-lab/bars/`。在选定时点计算盘中五项特征；标签为预留一根完整 K 线后，在随后一根 K 线按 VWAP 买入至下一交易日同一窗口 VWAP 卖出的价格变化。按交易日拆分训练、验证和留出日期，评估用户指定的 XGBoost 或 Elastic Net；全程只运行所选模型，模型仍标为探索性。训练不会自动运行回测或发布旧版绩效。

训练时优先使用东方财富 A 股快照；若连接失败则尝试新浪快照。XGBoost 的训练、回测拟合与排序预测会先探测 CUDA，运行环境中有可用 NVIDIA GPU 时使用 GPU，CUDA 不可用或运行失败时回退 CPU；Elastic Net 与数据采集仍由 CPU 执行，日志会显示 XGBoost 的计算设备。历史 BaoStock 回填串行进行，近期东方财富分钟线最多 2 路并发，新浪分钟线备用源串行访问。数据不足或模型训练失败时保留已发布的旧模型，不发布不完整模型；若所选模型验证期未达正向门槛，则发布带明确警告的探索性模型。首次回填 40 只股票的一年以上分钟线可能较慢；日志显示每只股票的累计交易日数和失败原因。
若两个实时快照源都不可用，“一键训练”可沿用最近 30 天的已缓存股票池和分钟线；命令行 `python scripts/factor_lab.py train-cached` 可明确使用本地缓存重训。缓存训练仍带有当前股票池的历史选股偏差。
2. **一键回测**：发现本地缺少逐日历史股票池、交易状态或验收清单时，先自动运行历史数据准备流程；准备完成后只读取通过来源清单校验的本地分钟线、`data/factor-lab/universe-history.csv` 和 `data/factor-lab/market-state.csv`，不发布模型。股票池文件每行有 `day,symbol,known_at`；交易状态文件每行有 `day,symbol,has_price_limit,limit_up,limit_down,split_ratio,cash_dividend,dividend_pay_date,stock_credit_date,is_st,is_suspended`。历史数据缺失、重复、非停牌股票缺少完整行情或哈希校验失败时，回测拒绝生成绩效。因子回测固定使用所选模型，沿用相同的时间拆分与成熟标签重拟合规则；固定规则策略无需拟合。两种因子模型和八种固定策略均使用 120 个交易日预备期后的共同评估区间；下单前用信号 K 线价格和金额确定订单，预留一个完整 K 线后按下一根 K 线的 VWAP 与成交参与率模拟部分成交。默认 14:00 信号对应 14:05–14:10 执行窗口；科创板买入至少 200 股，其他股票按 100 股；执行 T+1、涨跌停阻断、手续费和滑点。现金红利净额在到账日后计入可用现金；送转股在实际上市交易日前计入资产，但不能卖出。保存 `data/factor-lab/backtests/<时间>/summary.json`、`equity.csv`、`trades.csv`、`folds.json`。
3. **一键排序**：控制面板保留已确认 A 股交易日、09:35–11:30 或 13:00–15:00 的候选池研究排序，使用面板所选策略，固定规则仅展示触发入场的前20名并独立归档。日报网页使用上文的独立“全市场盘中排序”入口，可直接在网页选策略并启动任务，展示全部有效评分。

4. **回测全部策略**：一次加载已验收数据，分别评估两种因子模型及八种固定策略，保存每项独立的结果与批次清单。某项失败会记录原因并继续其他策略，不生成该项绩效。训练、回测与排序过程中仍可打开 DSH Web、日报和回测页面；状态检测期间所有按钮及选择框禁用。

## 策略选择

固定规则为 A 股只做多的盘中基础策略，信号只读取截至所选时点的行情；每天选择最多 5 只，按统一的延后 VWAP、每日重审、仍在前五名则保留持仓、离开前五名后提交卖单的规则模拟成交，无信号时保留现金。参数未根据评估期调优：

| 选择 | 标识 | 入场 / 排名规则 |
| --- | --- | --- |
| XGBoost 因子模型 | `xgboost` | 只拟合 XGBoost，按预测分数排名；CUDA 优先、CPU 回退 |
| Elastic Net 因子模型 | `elastic_net` | 只拟合 Elastic Net，按预测分数排名；CPU 运行 |
| VWAP 均值回归 | `mean_reversion` | 价格低于信号时点日内 VWAP 至少 0.5%，按负偏离排名 |
| 盘中动量 | `momentum` | 开盘以来涨幅至少 0.5%，按涨幅排名 |
| 日内区间突破 | `breakout` | 价格位于截至信号时点区间顶部 5%，振幅至少 1%，且开盘以来上涨 |
| 均线金叉 | `ma_crossover` | 5 分钟 SMA(5) 上穿 SMA(20)，按正偏离排名 |
| MACD 金叉 | `macd` | 5 分钟 MACD(12,26,9) 的 DIF 上穿 DEA，按价格归一化柱差排名 |
| RSI 超卖反弹 | `rsi_rebound` | Wilder RSI(14) 从 30 以下回升到 30 或以上，按回升幅度排名 |
| 布林带回归 | `bollinger_reversion` | 收盘价从 20 根、2 倍总体标准差的下轨外回到带内，按回归幅度排名 |
| 唐奇安通道突破 | `donchian_breakout` | 收盘价上穿此前 20 根 K 线最高价；通道排除信号 K 线 |

固定策略共 8 个，另有 XGBoost、Elastic Net 两种因子模型，共 10 项可选。新增技术策略使用已完成的 **5 分钟 K 线**，不是 5/20 日线策略；每个交易日以前一有效交易日的 48 根 K 线预热，EMA 与 RSI 使用均值初始化，历史价格只按信号日前已发生的公司行为调整。金叉和回归须在选定的信号 K 线上触发，因此可能出现无信号日期。实时排序自动取得所需分钟线并排除尚未完成的 K 线，使用独立 `live-bars/` 缓存；完整定义及指标依据见[固定策略说明](fixed-strategies.md)。

命令行也可指定本次策略，不改控制面板保存的选择：`python scripts/factor_lab.py train --strategy elastic_net`、`python scripts/factor_lab.py backtest --strategy mean_reversion`、`python scripts/factor_lab.py rank --strategy momentum`；`python scripts/factor_lab.py backtest-all` 回测全部十项。设置保存在 `config/factor-lab.json` 的 `strategy` 字段，示例见 `config/factor-lab.example.json`。

## 回测结果与限制

独立回测页面 `http://127.0.0.1:8766/backtests`（局域网访问使用本机 IP）展示各策略最新的收益、最大回撤、Sharpe 与交易次数；可切换历史记录查看累计净值、回撤曲线，并下载净值 CSV 和交易明细。完成回测后自动通知已打开的页面；未打开时下次访问仍可读取结果。每条记录标明评估日期和信号时点，不同日期、时点或数据版本的结果应分别比较。历史自动选模结果保留在历史下拉列表中，单独标为历史因子回测。

回测引擎版本 4 已修正日内区间突破阈值并加入五分钟技术指标策略；沿用版本 3 冻结全部订单的信号期预算，补齐过户费、历史印花税率和保守分红税预留；结果包含费用/滑点加倍与 2% 成交参与率压力测试。开始回测前会保存策略、时点、数据和代码哈希的研究计划，所有比较仍是探索性研究，未做多重检验校正。回测页面保留并标记旧引擎结果，修改前的结果需重新运行；六类偏差的详细检查与剩余限制见 [回测审计](backtest-audit.md)。

旧版固定股票池回测保存在磁盘用于审计，但回测页面不再展示其绩效。新版逐日股票池与交易状态需要可靠历史数据源，不能从现有 40 只股票缓存倒推。因子回测重放指定模型的逐窗口训练规则，不代表当前发布模型权重的历史收益。固定规则回测使用预先确定的参数。5 分钟 OHLCV 没有真实盘口，VWAP、成交参与率和滑点仍为假设；停牌持仓按最近收盘价估值，末日持仓不强制卖出。实时快照没有逐股报价时间戳，实时排名与回测特征可能存在时差，因此排名不作为收益概率或买入指令。
