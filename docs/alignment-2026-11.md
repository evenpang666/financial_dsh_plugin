## 启动修复：原生 pnpm 入口

实际启动发现 pnpm 12.3.4 的入口为包目录内的 `pnpm.exe`，旧启动器将其当成 JavaScript 脚本，加入错误的 PATH 目录。现按原生可执行文件与 JavaScript 入口分别处理，并统一 Windows PATH 变量大小写，支持发现 PATH 上的 `.exe` 工具。

新增无全局 pnpm、路径含空格的真实 Windows 子进程测试；JavaScript 回归更新为 128 项全部通过。使用项目内 pnpm 重试真实 DSH 插件注册成功，工作台已从正常启动器启动，服务地址为 `http://127.0.0.1:3205`。此次启动验证未发起付费模型调用。
