AKAgent 将对话研究、双时点日报、可视化市场概览与策略验证放在同一工作台。**20 个研究工具、8 个内置 Skills、2 种因子模型与 8 种固定策略**，覆盖从查证到复盘的研究流程。

> 本项目用于研究，不连接券商账户或执行交易。买入 / 卖出倾向是证据方向评分，不是仓位、涨跌概率或收益承诺。

## 主要特征

| 能力 | 你可以做什么 |
| --- | --- |
| 🔎 **A 股 / 港股研究** | 按代码或名称查找标的，结合行情、技术指标、财务与估值分析；A 股还支持公告与同行龙头核验。 |
| 🌐 **市场全景** | 汇总全球指数、政策与事件线索，查看市场宽度、关注情绪代理和风险等级。 |
| 🗓️ **双时点日报** | 交易日北京时间 **09:20 / 14:30** 生成两期报告；下午逐项对照上午结论，归档快照与反思。 |
| 📊 **可视化工作台** | 阅读市场图解、候选热力图和事件线索，切换历史日报；支持手机阅读、SVG 下载与打印。 |
| 🧪 **策略研究与回测** | 选择 XGBoost、Elastic Net 或八种固定策略，验收历史数据后模拟成交，查看净值、回撤与交易明细。 |
| 🧩 **按需持仓与排序** | 保存本地研究清单，比较三组研究配置；在网页发起 A 股全市场盘中排序。 |
| 🖥️ **跨平台控制面板** | Windows / Linux 统一管理服务、安装修复、更新与研究任务；可选 Webhook 推送。 |

## 快速开始

**准备环境：** Node.js 22 LTS、Python 3.11+；Linux 另需 Git，使用系统 Python / Tk 打开桌面控制面板。首次启动需要联网，启动器会安装缺失的 dsh、pnpm、Python 依赖并注册本地插件。

### 1. 启动控制面板

**Windows：** 双击项目根目录的 [`control_panel.cmd`](control_panel.cmd)。也可在项目根目录的 PowerShell 运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\bootstrap-control-panel.ps1
```

**Linux 桌面：** 在项目根目录运行：

```bash
./control_panel.sh
```

### 2. 配置模型

控制面板启动服务后，点击 **“打开 DSH Web”**，在 **“设置 → 模型”** 填写 DeepSeek API Key。密钥不要写入项目文件或提交到 Git。

### 3. 打开研究工作台

| 入口 | 用途 |
| --- | --- |
| 控制面板 → **打开 DSH Web** | 对话检索、单股研究与持仓清单管理 |
| [日报工作台](http://127.0.0.1:8766) | 历史日报、市场图解、按需持仓分析与全市场排序 |
| [回测工作台](http://127.0.0.1:8766/backtests) | 策略结果、净值与回撤曲线、CSV 明细 |

启动时不会自动打开浏览器。Linux 服务随当前登录会话运行，关闭控制面板会停止对应服务；重新登录后请再次启动。

安装修复、局域网访问和更新方式见[安装指南](docs/getting-started.md)。日常生成日报与运行回测可直接按下方步骤操作。

## 日报使用

1. **确认服务运行。** 启动控制面板，等待“日报任务”“数据服务”“日报页面”显示为“运行中”。首次使用无需保存持仓，也能生成市场日报。
2. **生成第一份日报。** 点击“网页入口”中的 **“手动生成日报”**，在运行日志中查看取数与生成进度。默认北京时间 14:30 前生成日报1，之后生成日报2；非交易日会跳过。
3. **阅读与切换。** 点击 **“打开日报”**，或访问 [日报工作台](http://127.0.0.1:8766)。通过“报告日期”选择历史报告及日报1 / 日报2，点击“刷新”读取更新；先看本期速览、市场图解和候选对比，再查看事件与完整正文。下午日报会对照上午结论复盘。
4. **按需研究持仓或全市场。** 持仓分析需先在 DSH Web 保存研究清单，再展开日报页面的“研究工具”，点击 **“分析我的持仓”**。全市场排序则选择策略 / 模型后点击 **“开始盘中排序”**；这些结果独立于归档日报。

启用日报任务后，交易日默认在 **09:20 / 14:30** 自动生成两期报告，保存在 `data/reports/`。手动生成会更新本地归档，不执行远程 Webhook 推送，也不影响当天定时任务。生成成功后默认自动打开报告；可在 `config/daily-push.json` 设置 `"auto_open_report": false` 关闭此行为。

修改市场、调度时间或配置 Webhook 推送时，再查看[日报与推送配置](docs/daily-reports.md)。

## 回测使用

1. **选择策略与时点。** 在控制面板的 **“策略 / 模型”** 中选择 XGBoost、Elastic Net 或固定规则策略，设置回测信号时点（默认 **14:00**）。首次可选择“盘中动量”等固定规则，无需训练。
2. **运行所选策略。** 点击 **“一键回测”**。缺少逐日历史数据时，面板会提示并自动下载、验收，通过后继续回测；首次准备可能耗时较长，请查看运行日志。下载或验收失败时不会生成绩效。
3. **查看结果。** 完成后点击 **“打开回测”**，或访问 [回测工作台](http://127.0.0.1:8766/backtests)。查看收益、最大回撤、Sharpe 和交易次数，切换历史记录查看净值与回撤曲线，并下载净值 CSV 与交易明细；必要时点击“刷新结果”。
4. **比较全部策略。** 点击 **“回测全部策略”**，在同一批已验收数据上评估两种因子模型与八种固定策略。各项独立保存结果，失败项保留原因；比较时确认评估日期、信号时点与数据版本一致。

**“一键训练”与“一键回测”是独立操作：** 前者生成供盘中排序使用的因子模型，不会自动产生回测结果；因子回测会按历史窗口重新拟合，固定规则无需拟合。回测输出保存在 `data/factor-lab/backtests/`，并模拟 T+1、涨跌停、手续费、滑点与成交限制，结果仅供研究。

自定义历史区间、命令行操作与数据验收细节见[因子研究指南](docs/factor-lab.md)，策略定义和回测假设分别见[固定策略](docs/fixed-strategies.md)与[回测审计](docs/backtest-audit.md)。

## 开始一次研究

在 DSH Web 中发送：

```text
请研究 600519，数据截止到最近一个可得交易日。
先查询行情、技术指标、财务与公告，再分别判断短期和长期情况。
列出已确认事实、来源与日期，给出结论、买入/卖出倾向和结论失效条件。
百分比不得解释为仓位或涨跌概率；缺少证据时明确说明。
```

研究港股可发送：`请研究腾讯控股，使用 market=hk，先检索并确认代码。`

更多提示词、Skills 和评分说明见[研究指南](docs/research-guide.md)。

## 数据与使用边界

以工具的 `as_of` 和来源日期为准；数据缺失时保留缺失状态。公共数据源可能延迟或变更，历史回测仍属于探索性评估，不代表未来收益。本项目的研究输出不属于持牌证券投资咨询。

详细的数据时效、授权和回测限制见[研究指南](docs/research-guide.md)、[工具说明](docs/tools-and-markets.md)与[回测审计](docs/backtest-audit.md)。
